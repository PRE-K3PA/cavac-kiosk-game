`AGENTS.md`, `TEAM_OWNERSHIP.md`, `.claude/rules/clean-code.md` 를 읽고 따릅니다.

## 범위

- 이번 작업에서 변경된 파일만 대상으로 합니다 (`git diff develop...HEAD`, `git status`)
- 프롬프트에 허용 파일 범위가 있으면 그 안에서만 수정합니다
- 변경되지 않은 파일, 다른 담당자의 관련 없는 파일은 수정하지 않습니다
- **동작을 바꾸지 않습니다.** 화면, 인터랙션, 데이터 흐름, 공개 props 와 타입이 그대로여야 합니다

## 다듬는 것

- 같은 파일 안의 중복 로직
- 이미 있는 Common 컴포넌트, 훅, 유틸리티로 바꿀 수 있는 코드
- 불필요한 `useEffect`, `useMemo`, `useCallback`
- 파생 가능한데 따로 저장한 상태
- 깊은 중첩 (early return 으로 펼치기)
- 의미 없는 래퍼, 한 번만 쓰는 불필요한 추상화
- 모호한 이름
- 코드만 봐도 알 수 있는 주석

## 하지 않는 것

- 새 공용 코드 생성
- 파일 이동, 폴더 구조 변경
- 코드 줄 수만 줄이기 위한 압축
- 새 패턴이나 라이브러리 도입

애매하면 고치지 않고 보고만 합니다.
